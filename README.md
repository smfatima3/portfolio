## Ongoing research

- **[AgentRoute](https://github.com/smfatima3/AgentRoute)** — Selective communication for multi-agent LLM reasoning, with matched dense and no-communication controls. Model-level evaluation is available; transport validation remains incomplete.
- **[Persistent Memory and Residual Robot Safety Risk](https://github.com/smfatima3/workIN)** — Studies whether source revocation restores safe behavior in communicating robots, using simulation and memory-recovery policies. Exploratory foundation and replication evidence is available.
- **[Preventing Task Interruption Hazards](https://github.com/smfatima3/Preventing-Task-Interruption)** — Action-conditioned supervision and recovery for humanoid tasks. Component validation has been released; later safety and nominal-task evaluations remain ongoing.
- **[On the Same Ruler: Latency, Throughput, Energy, and Unit-Economic Cost of LLM Safety Mechanisms at Operational Scale](https://github.com/smfatima3/LLM-Safety-Mechanisms-at-Operational-Scale)** — A common measurement harness for comparing safety mechanisms across GPU architectures.
- **[OptiMoE: Routing-Aware Straggler Prediction for MoE RL Post-Training](https://github.com/smfatima3/OptiMOE)** — Investigates early expert-routing signals for predicting generation stragglers; final scheduling speedup is not established.

Research artifacts are not represented as standalone preprints or accepted papers.
